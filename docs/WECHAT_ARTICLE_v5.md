# 洋芋田图像工具箱 5.0：一次从头开始的重写

> 距离上一次给图像工具箱写版本推送，已经过去了很久。这期间它没有停止维护，但在我心里，它一直欠着一次「从头再来」。
>
> 现在，这次重写终于完成了。

![主界面](../../potatofield-frontend/src/Assets/Images/ImageToolkit/hero.png)

洋芋田图像工具箱是我做的第一款真正意义上的桌面软件，也是我用得最多的一款。它陪我从学生时代走到现在 —— 用户群里一直就那么些老朋友，人不多；但前些天翻后台数据时，我自己也愣了一下：**累计已经有 12 万人装过它，月活超过四千**。

对一个只用业余时间写着玩、顺手还开源出去的小工具来说，这是我从来没敢想过的数字。

但坦白讲，它的「底子」已经很旧了：内核是 Electron 11 + Vue 2，构建工具是 Webpack 4，界面用的是几年前的 Element UI。日常修修补补还行，想再往上做点什么，每一步都很吃力。

所以这一次，我没有再加功能，而是把它整个推倒重来。

## 一、新的技术底座：更快、更稳，也更省

先说结论：**同样的电脑，处理同样的图片，新版本会明显更快，而且界面不会再卡。**

具体做了这些事：

### 1. 内核整体换代

应用框架从 Electron 11 升级到 **Electron 44**，界面框架从 Vue 2 换到 **Vue 3**，开发语言全面使用 **TypeScript**，构建工具换成了 **Vite**。

这些名词不需要记，它们带来的实际变化是：启动更快、内存占用更低、长时间处理大量图片时更稳定。

### 2. 图像处理搬到了「后台」

老版本里，图片的缩放、压缩、水印合成是在界面所在的进程里跑的。好处是写起来简单，坏处也很明显：**一旦开始处理，界面就容易卡顿甚至转圈**，尤其是大图或者大批量的时候。

新版本把这些重活儿全部挪到了主进程，交给专业的图像库 **sharp（libvips）** 去做，并且可以**吃满 CPU 的多个核心**。

结果是：不管在批量处理多少张图，界面都能继续流畅滚动、切换、预览。

![批量处理](../../potatofield-frontend/src/Assets/Images/ImageToolkit/batch.png)

### 3. 大图不再「卡死」

以前遇到一张超大的图，软件很容易直接失去响应。现在：

- 预览会自动等比缩小（长边不超过 10000 像素、总像素不超过 600 万），不会因为一张图就吃掉几个 G 的内存；
- 真正导出时仍然按照**原始尺寸**输出，画质不受影响；
- 超过 libvips 的像素上限（约 2.68 亿像素）时，会提前给出中文提示并禁用保存，而不是让你等半天之后崩溃。

### 4. 水印图片不再「失踪」

老版本的水印模板记的是图片在你电脑上的路径，一旦原图被移动或删除，模板就失效了。现在水印图会被复制进应用自己的数据目录，并按**内容指纹**命名：同一张图只存一份，多个模板可以共用，删模板时也没有垃圾残留。

## 二、统一的视觉：和你的系统长在一起

这次重写的另一个重点，是让它的「长相」追上另外两个产品。

### 1. Fluent Design，与 Windows 11 同一套设计语言

界面全部换成了微软的 **Fluent Design** 体系（和 Windows 11 设置、PowerToys 是同一套设计语言）：设置卡片、滑块、开关、下拉框、按钮，全部统一。

参数面板做成了 Windows 设置那样的分组卡片，相关的选项可以折叠 —— 一屏之内能看清所有参数，不用上下翻。

![设置](../../potatofield-frontend/src/Assets/Images/ImageToolkit/settings.png)

### 2. 深色模式 + 自定义主题色

深色模式不是简单地「反个色」，而是完整的一整套暗色配色；主题色也不再是固定的蓝色，你可以在设置里任选一个颜色，软件会自动生成一整条**品牌色阶**，按钮、选中态、指示条会跟着变，并且**所有窗口实时同步**。（也可以选择**跟随系统**，系统切换深浅色时软件会立刻跟着变。）

![深色模式主界面](../../potatofield-frontend/src/Assets/Images/ImageToolkit/hero-dark.png)

### 3. 窗口材质

在 macOS 上支持系统级的**玻璃质感**，在 Windows 11 上支持**亚克力材质**，窗口不再是糊在桌面上的一块色块。（较老版本的 Windows 也有兼容方案。）

## 三、功能升级：不只是「都有」，而是更好用

十二个工具都还在：加水印、裁剪、长图拼接、分割、尺寸调整、压缩、格式转换、EXIF 读取、色彩提取、字体管理，以及新独立的模板管理。

这次的变化主要在下面几处：

### 1. 批量处理：真正可以「放着不管」

支持批量处理的工具从 1 个扩展到了 **5 个**（加水印、裁剪、尺寸调整、压缩、格式转换），并且：

- 可以直接**扫描整个文件夹**（递归子目录），并**保持原有的目录结构**输出；
- 开始处理前，如果发现会有同名文件，会让你选择：**自动重命名 / 覆盖 / 取消**，不会默默帮你决定；
- 处理过程中可以随时**取消**，已经完成的文件会保留，不会前功尽弃；
- 单个文件失败不会中断整批，结束后可以直接打开输出目录看结果；
- 处理过程中点关闭（或从托盘退出）会先问你：**中断并关闭 / 最小化到托盘 / 取消** —— 选「最小化到托盘」，它会缩到托盘继续跑，不耽误你用电脑。

![批量处理](../../potatofield-frontend/src/Assets/Images/ImageToolkit/batch.png)

### 2. 水印模板：调一次，用很久

水印参数常常是「调一次要用很久」的东西，所以这次单独做了**模板库**：

- 调好后可以**存为模板**，下次一键应用；
- 模板库是独立窗口，带侧边栏、卡片列表，模板多了可以**搜索**；
- 支持**重命名 / 另存 / 删除**，删除时有二次确认；
- 编辑模板时会打开独立的**模板编辑窗口**：左边实时预览（用中性底图呈现位置与大小），右边调参数，不用来回切换；
- 所有改动**跨窗口实时同步**，在一个窗口改完，另一个窗口立刻看到；
- 文字水印的字体，可以直接用**你系统里已安装的任意字体**（详见后面「字体与色彩」）。

![水印模板库](../../potatofield-frontend/src/Assets/Images/ImageToolkit/template.png)
![模板编辑](../../potatofield-frontend/src/Assets/Images/ImageToolkit/template-editor.png)

水印本身的位置与大小计算也重写了：支持**百分比**和**像素**两种单位，允许水印比图片大、允许有意溢出到图外，渲染后会自动去掉透明留白，所见即所得。

![加水印](../../potatofield-frontend/src/Assets/Images/ImageToolkit/watermark.png)

### 3. EXIF 读取：不再甩给你几百条废数据

老版本会把图片里所有元数据一股脑列出来，动辄几百项，绝大多数是厂商私有标签，根本没法看。

新版本只保留**摄影爱好者和设计师真正会看**的字段，并分好组：

- **文件**：格式、文件大小、DPI、是否内嵌 ICC 色彩配置
- **图像**：尺寸、像素总数、色彩空间、位深、通道、是否含透明通道、方向
- **拍摄信息**：相机厂商、型号、镜头、拍摄时间
- **曝光参数**：快门（显示为 1/125 秒）、光圈（f/2.8）、ISO、焦距与等效焦距、曝光补偿、测光模式、白平衡
- **拍摄位置**：有 GPS 信息时显示经纬度与海拔
- **归属与说明**：作者、版权、处理软件

![EXIF 读取](../../potatofield-frontend/src/Assets/Images/ImageToolkit/exif.png)

### 4. 字体与色彩：自定义字体这次是真的了

先说一个容易被忽略、但我自己很在意的变化。

老版本里也有「自定义字体」，但说白了它并不算：你能选的只有软件内置的几款，**你自己在电脑上装了什么字体，它一概不知道**。想用花钱买的字体、从网上下载的字体，或者客户指定要用的那一款，根本选不到 —— 只能将就。

新版本会直接读取**你系统里已安装的全部字体**：加水印时想用哪一盏就用哪一盏；字重也按字体本身的真实样式列出来（细体 / 常规 / 中等 / 粗体……），不再靠「加粗」开关硬凑一个出来。

![字体管理](../../potatofield-frontend/src/Assets/Images/ImageToolkit/fonts.png)

字体管理本身也照旧好用：支持**在线字体一键安装到系统**，本地字体可以按**字体本身的字体**预览，搜索支持中文别名（搜「雅黑」能找到 Microsoft YaHei）。

色彩提取会从图片里直接取出主色，点击色卡即复制色值。

![色彩提取](../../potatofield-frontend/src/Assets/Images/ImageToolkit/palette.png)

### 5. 其余工具的细节

- **长图拼接**：支持拖拽排序、可选边距与底色，横向等高 / 纵向等宽对齐；
- **裁剪**：单图与批量共用同一套参数与换算逻辑，行为完全一致；
- **压缩 / 格式转换 / 尺寸调整**：默认输出格式与质量统一读取设置页的「默认输出」，不用每个工具各调一遍；
- **单图工具**：统一为「先处理，再选择保存位置」，不再被常驻的保存路径打扰。

![长图拼接](../../potatofield-frontend/src/Assets/Images/ImageToolkit/splicer.png)
![裁剪](../../potatofield-frontend/src/Assets/Images/ImageToolkit/cropper.png)

## 四、老用户可以无缝升级

这一点我花了不少心思：**更新服务器和软件标识都保持和老版本一致**。

也就是说，如果你电脑上装的是 3.x 的旧版本，打开软件就会收到更新提示，按提示即可**直接自动升级到 5.0**，不需要卸载重装，也不需要重新下载安装包。

顺带一提，如果你在旧版本里保存过水印模板，第一次打开新版本时会**自动导入**，不会丢。

## 更新或下载

**已安装旧版本的用户**：打开软件即会弹出更新提示，按提示自动更新即可；也可以在设置界面手动检查更新。

**还没有安装过的用户**：欢迎访问 [https://potatofield.cn/imagetoolkit](https://potatofield.cn/imagetoolkit) 或点击下方的「阅读原文」获取，我们提供 **Windows** 与 **Mac** 的安装包。
