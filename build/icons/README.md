# 图标目录

打包（electron-builder）需要以下图标文件，请从老项目复制：

```
PotatofieldImageToolkit/build/icons/icon.ico   -> 本目录/icon.ico   (Windows)
PotatofieldImageToolkit/build/icons/icon.icns  -> 本目录/icon.icns  (macOS)
PotatofieldImageToolkit/build/icons/icon.png   -> 本目录/icon.png   (托盘)
```

开发模式（npm run dev）不需要这些图标。
